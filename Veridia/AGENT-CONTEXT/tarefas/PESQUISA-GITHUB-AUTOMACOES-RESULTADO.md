## 1. Método, fontes e limitações

- **Busca de repositórios:** API `https://api.github.com/search/repositories` sem autenticação, via WebFetch (o proxy desta sessão bloqueia `api.github.com` para curl; `gh` não existe aqui). Foram 63 chamadas WebFetch, incluindo as que falharam ou voltaram vazias. Em `COMANDOS.txt` as consultas em lote `repo:A+repo:B` aparecem agrupadas. As consultas foram: consultas por tópico (`runelite`, `osrs`, `rsps`, `osrs-bot`, `runescape`), por termo (microbot, parabot, "rsps bot", "osrs bot", dreambot, osbot, tribot, powerbot/rsbot/epicbot/rspeer, webwalker, pathfinding, osrs server, near-reality, kronos, elvarg, osrsbox/osrs cache, wiki scraper, unethicalite/openosrs/devious, ethanapi/piggy, "tormented demon"/"gemstone crab"/"chaos altar", kraken), por organização (`user:` rsmod, blurite, openrs2, Parabot, OSRSB, chsami, Skretzo, osrs-pathfinding, Explv, Zoinkwiz, weirdgloop, osrs-wiki, RuneStar, abextm, mejrs, near-reality-com) e por forks (`in:name fork:only`). Também fiz 7 buscas web. A lista completa está em `COMANDOS.txt`, seção 2.
- **Limite da ferramenta:** cada consulta devolveu no máximo ~20 itens legíveis, mesmo com `per_page` maior. Por isso usei consultas mais estreitas em vez de paginar tudo. Resultados fora de RuneScape (Azure SDK, OWASP OSBot, bots de Telegram...) não contam como candidatos.
- **Busca de código (passo 2 do pedido): não foi possível no GitHub inteiro.** `search/code` exige login e grep.app/Sourcegraph estão bloqueados pela política de rede. Fiz a busca **localmente**: nomes de arquivo nas 254 árvores (ex.: `transports/*.tsv`, `*Dumper*`, `thiev|stall`, `random`, `prestige`) e conteúdo nos 25 clones (ex.: `prestige`, `menuAction`, `setAccessible`, `Proxy.newProxyInstance`, `BoundFieldModule`).
- **Listas awesome:** só existe `ar1a/awesome-runelite` (1 estrela, parada desde 12/2017). Não há `awesome-osrs` nem `awesome-rsps` no GitHub (busca `awesome in:name` + termos, 29/09/2026).
- **"Used by":** a página do GitHub não é acessível daqui. Em vez dela usei o índice `runelite/plugin-hub` (2.785 manifests `repository=`/`commit=`) para achar plugins que usam a API pública.
- **Abertura:** para cada um dos 254 candidatos, rodei `git clone --bare --filter=blob:none --depth 1` e listei a árvore com `ls-tree`. Licença e README foram lidos direto do arquivo (`git cat-file`). A licença do CSV é a do **arquivo**, não a que a API deduz. Onde as duas divergem, vale o arquivo: por exemplo, rsmod, OpenRune-Server e openrs2 são ISC e Parabot-317-API-Minified é GPL-2.0.
- **Clones:** 25 repositórios com `--depth 1` (sparse onde o repositório é grande), mais `fetch --depth=60` no shortest-path para ver o histórico do mapa de colisão. Nenhum gradlew/mvnw/npm/.bat/.ps1/.sh foi executado e nenhum .jar/.exe foi aberto.
- **Pontuação (/11):** relevância 0–3 + compatibilidade 0–3 + qualidade/testes 0–2 + atividade 0–2 + licença 0–1.
  - **Compatibilidade:** 3 = API pública do RuneLite, compila com pouca mudança; 2 = API pública, mas precisa tirar Lombok ou trocar a camada de interação; 1 = só a lógica serve (Rs2*, DreamBot/TriBot, Kotlin de servidor, dados sem licença); 0 = exige cliente injetado ou só tem binário.
  - **Atividade:** 2 = commit desde 01/07/2026; 1 = desde 29/09/2024; 0 = mais antigo.
  - **Licença:** 1 = arquivo com licença OSI.
  - **Qualidade:** 2 = ≥10 arquivos de teste e código organizado; 1 = organizado; 0 = mínimo. Fork sem código próprio recebe 0 aqui, porque a qualidade é herdada.
